# Party Site UI kit
Click-through party website built from the moodboard. No real product existed, so layouts are composed from reference motifs, not copied.
- **Home:** animated ember ShardBurst hero (cursor parallax, click to re-detonate) + glitching mega headline + numbered IndexLink menu; RetroTV on a white studio floor flipping channels next to a Verdana news column; Bauhaus-orange ThumbNav; typo5-style "party dESIGN" crop-line collage with Win2000 "join / drop" form.
- **Lineup:** crimson, tall glitching title, set rows that flash red and skew on hover.
- **Gallery:** paper ShardBurst header, typo5 link-list sidebar filter, mono glitch photo frames.
- **RSVP:** crimson abstract, dark form → white strobe → Win2000 dialog → toast.
- Global: CRT-off/on page transitions, red crosshair cursor with coordinates.
Files: index.html, FX.jsx, Header.jsx, Footer.jsx, Home.jsx, Lineup.jsx, Gallery.jsx, Rsvp.jsx.
