Corner-cut compressed-caps slab button with an offset echo (lifts + glitches on hover, presses on click); `variant="classic"` gives a grey Win2000 bevel button for "join / drop" style form actions.
```jsx
<Button index={1} arrow>Get on the list</Button>
<Button variant="classic">join</Button>
```
Variants: primary, secondary, flash (on dark), orange, ghost, classic. Sizes sm/md/lg.
